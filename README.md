# Where the Stars Fell

**Put it online (2 minutes):** go to app.netlify.com/drop and drag the `site` folder onto the page. Or, in your existing Netlify site, deploy this `site` folder the same way you deploy Lost in Orbit.

**Open it on her phone:** visit the link, then "Add to Home Screen". It opens full-screen and works offline after the first load. Progress saves on her phone.

**Edit the personal lines:** `src/personal.js`, then run `npm install` once and `npm run build`.

**Test a specific part:** add `?debug=1&cp=day1_day&autostart=new` to the link (checkpoints: prologue, day1_morning, day1_day, day1_end).
